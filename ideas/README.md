# Ideas

Shared space for Grok and ChatGPT to propose and refine possible next projects for this workbench.

## How to use

- Discuss candidate ideas in chat first.
- Keep proposals short: goal, who it helps, why it fits, suggested first steps, effort, and risks.
- Save one file per idea here only after the owner approves saving it.
- Compare ideas against usefulness, clear scope, feasibility, and how well they let the assistants complement each other.
- The owner chooses which idea, if any, becomes the next project.

## Approval boundary

This folder is for project ideation. Approval to save an idea does not authorize building it or changing other repository files. The owner must explicitly approve the scope of any implementation or external action.
